Dashboard integral de control de obra
Prompt 01 · Project Controls, Lean y EVM
Actúa como **Project Controls Manager, especialista PMP, Lean Construction y Earned Value Management (EVM)**, y desarrollador experto en dashboards de gestión de construcción.

**OBJETIVO:** Crear un dashboard web profesional, interactivo y completamente funcional para la **planificación, seguimiento y control integral de la construcción de un edificio multifamiliar de 5 niveles**, tomando como referencia la imagen adjunta.

### 1. Planificación del proyecto
- EDT/WBS jerárquica: fases, entregables, partidas y actividades.
- Cronograma Gantt interactivo con dependencias, hitos y ruta crítica (CPM).
- Línea base contractual vs. planificación vigente vs. avance real.
- Planificación maestra, lookahead de 3–6 semanas y plan semanal.
- Curva S programada, real y de valor ganado.
- Control de recursos: personal, equipos, maquinaria y materiales.

### 2. Seguimiento físico y financiero
- Avance físico por partida, especialidad, nivel y frente de trabajo.
- Metrados programados, ejecutados, aprobados y pendientes.
- Presupuesto contractual, costos reales, compromisos y proyección final.
- Flujo de caja, valorizaciones, adicionales y órdenes de cambio.
- Productividad de cuadrillas, HH consumidas y rendimientos.
- Registro diario de obra, fotografías, incidencias y restricciones.

### 3. Gestión del Valor Ganado (EVM)
Implementa cálculos automáticos con las siguientes métricas:

- **BAC:** presupuesto total aprobado.
- **PV (BCWS):** valor planificado.
- **EV (BCWP):** valor ganado.
- **AC (ACWP):** costo real.
- **CV = EV − AC:** variación de costos.
- **SV = EV − PV:** variación del cronograma.
- **CPI = EV / AC:** índice de desempeño de costos.
- **SPI = EV / PV:** índice de desempeño del cronograma.
- **EAC:** estimación del costo final, con escenarios configurables.
- **ETC = EAC − AC:** costo pendiente estimado.
- **VAC = BAC − EAC:** variación estimada al cierre.
- **TCPI:** desempeño requerido para cumplir el presupuesto.

Incorpora indicadores tipo semáforo, análisis de tendencias, proyecciones y alertas ante desviaciones. Distingue explícitamente el SPI del EVM de la medición de atraso basada en ruta crítica.

### 4. Control operativo integral
- Calidad: inspecciones, ensayos, protocolos y no conformidades.
- Seguridad: incidentes, observaciones, inspecciones y acciones correctivas.
- Abastecimiento: órdenes de compra, entregas y materiales críticos.
- Riesgos: matriz de probabilidad-impacto y planes de respuesta.
- Restricciones, RFIs, submittals y aprobaciones pendientes.
- Responsables, compromisos, fechas límite y trazabilidad.

### 5. Diseño del dashboard
Desarrolla una interfaz premium tipo **Power BI + Primavera P6 + Autodesk Construction Cloud**, con fondo claro, gráficos interactivos, navegación lateral y diseño responsive.

Incluye vistas de:
1. Resumen ejecutivo con KPIs.
2. Planificación y cronograma Gantt.
3. Avance físico y Curvas S.
4. Valor Ganado (EVM).
5. Costos, presupuesto y flujo de caja.
6. Productividad y recursos.
7. Calidad, seguridad y riesgos.
8. Abastecimiento y restricciones.
9. Reportes gerenciales y proyecciones.

### 6. Funcionalidad y datos
- Filtros por fechas, niveles, especialidades, contratistas y partidas.
- Carga y exportación de Excel/CSV.
- Edición de registros y actualización automática de métricas.
- Comparación histórica por períodos de corte.
- Drill-down desde indicadores hasta actividades y partidas.
- Reportes PDF ejecutivos y reportes semanales.
- Alertas visuales y recomendaciones de acciones correctivas.
- Persistencia de datos y trazabilidad de cambios.

**ENTREGABLE:** Dashboard web funcional, visualmente elegante y preparado para incorporar datos reales. Utiliza React, TypeScript, Tailwind CSS y Recharts. Incluye datos simulados coherentes para demostrar su funcionamiento, claramente identificados como demostrativos.

**CRITERIOS:** Todas las métricas deben calcularse a partir de los registros, no ser valores estáticos. Mantén consistencia entre WBS, presupuesto, programación, metrados y costos. Implementa estados vacíos, validaciones y manejo de divisiones por cero. Prioriza precisión de ingeniería, usabilidad gerencial y capacidad de escalamiento.
Diseño UI/UX con identidad GEN+
Prompt 02 · Plataforma SaaS profesional
DISEÑO UI/UX — IDENTIDAD GEN+
Diseña el dashboard integral de planificación, seguimiento y control de obra utilizando como referencia visual obligatoria https://www.genplusdesign.com/.
Analiza su lenguaje visual y trasládalo a una plataforma SaaS profesional de gestión de construcción.
Lineamientos visuales:

* Estética premium, tecnológica, minimalista y corporativa, alineada con GEN+.
* Reutiliza la identidad gráfica, tipografía, colores, contrastes y componentes del sitio de referencia, verificando sus estilos reales.
* Predominio de superficies limpias, jerarquía tipográfica marcada, espaciado generoso y composición modular.
* Sidebar elegante y colapsable, encabezado ejecutivo y navegación intuitiva.
* KPI cards sofisticadas, gráficos interactivos, tablas avanzadas, Gantt y Curvas S con diseño consistente.
* Microinteracciones, transiciones fluidas, efectos hover y animaciones discretas.
* Semáforos de desempeño con colores funcionales, sin alterar la identidad GEN+.
* Diseño responsive, optimizado prioritariamente para escritorio y pantallas de control gerencial.

Pantalla principal: Executive Project Control Center
Debe mostrar inmediatamente:

1. Render arquitectónico del proyecto y datos generales.
2. Avance físico programado vs. ejecutado.
3. Presupuesto BAC, PV, EV, AC y EAC.
4. CPI, SPI, desviaciones CV/SV y proyección financiera.
5. Curva S interactiva.
6. Cronograma de hitos y actividades críticas.
7. Alertas, restricciones y riesgos prioritarios.
8. Resumen ejecutivo inteligente con recomendaciones accionables.

Experiencia de usuario: Inspirada funcionalmente en Autodesk Construction Cloud, Primavera P6 y Power BI, pero visualmente coherente con GEN+. Evita dashboards genéricos, saturación de tarjetas y elementos decorativos innecesarios.
Tecnología: React + TypeScript + Tailwind CSS + shadcn/ui + Recharts + Framer Motion. Utiliza un sistema centralizado de design tokens y componentes reutilizables.
Resultado: Una plataforma GEN+ Project Controls con apariencia de software empresarial comercial, navegación completa, datos conectados, métricas calculadas y visualizaciones interactivas. No entregar únicamente un mockup estático.
Aplicación de Computer Vision
Prompt 03 · MediaPipe y cámara web
Crea una aplicación web interactiva de Computer Vision para demostrar cómo funciona la inteligencia artificial aplicada al reconocimiento facial y de manos.

Funcionalidades:
- Activar la cámara web en tiempo real.
- Detectar rostros y manos, dibujando recuadros y puntos de referencia sobre ellos.
- Identificar gestos: mano abierta, puño cerrado y dedos levantados.
- Mostrar en un panel los elementos detectados, cantidades y niveles de confianza cuando estén disponibles.
- Visualizar en tiempo real cómo la IA interpreta los movimientos.

Tecnología: HTML, CSS, JavaScript y MediaPipe. Procesamiento local en el navegador, sin identificar personas ni almacenar imágenes.

Diseño: Premium, minimalista, fondo blanco con detalles verdes, estilo dashboard moderno. Interfaz visual y didáctica, animaciones fluidas y controles para iniciar y detener la cámara.

Objetivo: Crear una demostración visual, dinámica y completamente funcional para una presentación profesional sobre inteligencia artificial y visión por computadora.
